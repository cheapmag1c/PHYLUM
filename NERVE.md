# PHYLUM 1.4 — NERVE

**Organisms lived. Now they learn.**

NERVE is PHYLUM's persistent cognition and behavior layer. It sits above SOMA's organismal biology and inside the DEEP TIME / PALEON evolutionary loop.

## Core systems

- nervous-system architecture derived from inherited SOMA/genome state
- perception modalities and sensitivity
- bounded spatial/resource/threat/disease memory
- learning and memory decay
- inherited versus learned behavioral repertoires
- temperament: curiosity, caution, boldness and sociability
- cooperation, recognition, reciprocity and social signaling
- cultural traditions that persist without being treated as genes
- founder transmission of culture across speciation
- rare social learning / teaching
- cognition energy costs and demographic tradeoffs
- weak natural selection on cognitive architecture
- anatomy-gated, rare object-assisted foraging / tool-use pathway
- NERVE ethogram and static browser

## Design rule

NERVE does **not** schedule intelligence. There is no generation at which brains, culture, teaching or tool use are forced to appear. These are possible outcomes of inherited anatomy, ecology, selection, sociality and experience. Cognitive complexity can stall or regress when its energetic cost is not rewarded.

## Persistence

Each lineage stores a compact `nerve` object inside `world/species.json`. Memory, culture and repertoire are bounded so repository state cannot grow without limit. Descendant lineages inherit cognitive architecture, while ordinary learned memories are cleared at speciation and cultural traditions cross only through limited founder transmission.

## Observation

- `renders/nerve.svg` — current living-lineage ethogram
- `docs/nerve.html` — searchable NERVE browser
- `python -m phylum nerve` — machine-readable current NERVE state
- WITNESS marks behavior, learning, communication, culture and tool-use events
